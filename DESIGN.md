# Inspectr visual system

Light product workspace for daytime website review. Off-white canvas, slightly green neutral surfaces, dark green ink, forest green accent, restrained amber and red status colors. Colors use OKLCH CSS tokens.

Geist carries headings and UI; monospace is reserved for detected code values. Strong hierarchy, comfortable reading widths, consistent 14px labels and 16px body copy.

The desktop shell is 1120px wide. Home combines a primary URL form with a quiet instructional aside. Checks use separated rows. Reports use a category rail and a searchable result list. Mobile stacks columns and gives the category rail horizontal scrolling.

Buttons have 8px corners, complete interaction states, and clearly visible focus. Borders and subtle neutral fills distinguish surfaces. No gradients, glass effects, repetitive cards, or decorative animation. Reduced motion disables loading animation.
